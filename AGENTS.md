# Agent Guidelines & Workflow Rules

## MANDATORY RULE: Keep Root README.md Updated
Whenever ANY work, feature implementation, configuration change, bug fix, or deployment update is performed in this repository, you **MUST** update `README.md` in the root folder before concluding the task.

### Documentation Requirements in `README.md`:
1. **Changelog / Recent Updates:** Record what changed, the reason for the change, and the files modified.
2. **Setup & Deployment:** If any new environment variable, configuration, or build step is added, update the setup and deployment sections immediately.
3. **Architecture / Features:** Keep feature lists and endpoints synchronized with actual code.
